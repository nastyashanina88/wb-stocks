# WB Stocks

Скрипт для выгрузки остатков со складов Wildberries в XLSX-файл, веб-дашборд и Telegram-алерты.

## Возможности

- Загрузка всех остатков через API Wildberries (с пагинацией)
- Экспорт в `stocks.xlsx` с заморозкой заголовков
- Статус остатка: `in_stock`, `critical`, `out_of_stock`
- Вывод ТОП-10 критичных позиций в консоль
- Веб-дашборд с таблицей, поиском, сортировкой и статистикой
- Telegram-бот для отправки алертов о критичных остатках

## Установка

```bash
npm install
```

## Настройка

Создайте файл `.env` в корне проекта:

```
WB_API_TOKEN=ваш_токен_wildberries
TELEGRAM_BOT_TOKEN=токен_бота_telegram
TELEGRAM_CHAT_ID=id_чата_telegram
```

## Запуск

### Выгрузка в XLSX (как раньше)

```bash
node index.js
```

Результат сохраняется в `stocks.xlsx`.

### Веб-дашборд

```bash
node server.js
```

Открыть http://localhost:3000 — таблица с остатками, поиск, сортировка, цветовая индикация статусов.

### Telegram-алерты

```bash
node telegram.js
```

Отправляет список критичных позиций в указанный Telegram-чат.
